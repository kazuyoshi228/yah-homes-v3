## 2. 3つの市場は「同じ映画の別の場面」

インバウンドブームによる供給爆発という同じ映画を、進行度の違う3場面で見ている。

- **東京 = 崩壊後期（値下げ型）**: 供給+40.7%が続き、ホストが値下げで稼働を守る消耗戦。ADR-5.6%・RevPAR-9.7%。3年で供給4倍。
- **札幌 = 崩壊初期（空室型）**: 供給+57.1%に対しホストが強気価格を維持（ADR+6.2%）した結果、稼働-12.8%と空室で受ける展開。加えて季節が極端（冬3ヶ月で稼ぎ、4〜6月はRevPAR$65まで沈む）で、通年稼働モデルとは根本的に不適合。
- **福岡 = ゴールドラッシュ期（需要主導）**: 供給が3市場最速の**+104.3%（1年で倍増）**にもかかわらず、**稼働+1.7%・RevPAR+1.7%と両方プラス**。訪日九州需要（台湾・香港直行便）の成長が参入ラッシュを丸ごと吸収している。3市場で唯一「需要>供給」が成立。

## 3. 「福岡はあと何年で東京化するか」— 推定

**推定の骨格**: 東京化（=稼働・RevPARのマイナス転換）は「供給の成長率が需要の成長率を上回り続けた累積」で起こる。

- 福岡の需要成長（Booking Demand実測）: 予約泊数は3年で約250→900泊/月 ≒ **年+40〜50%**で成長中
- 福岡の供給成長: **年+104%**（ただし母数12→47件と小さく、率は今後自然減速する公算大）
- 東京の教訓: 供給が需要を上回ってから稼働マイナスが顕在化するまで約1年、RevPAR2桁下落まで約2年

**シナリオ**:

| シナリオ | 前提 | 東京化（稼働マイナス転換）の時期 |
|---|---|---|
| 悲観 | 供給+100%ペース持続・需要+40%へ鈍化 | **2027年後半**（約1〜1.5年後） |
| **基本** | 供給増が+50〜60%へ減速・需要+40%持続 | **2028年〜2029年前半**（約2〜3年後） |
| 楽観 | 供給増+30%台へ減速・万博/直行便増で需要+50%持続 | 2029年以降（3年超） |

**結論: 「無風の時間」はおおむね2〜3年、早ければ1年半。** ただし年数の予想を当てることより、**転換点を最初の四半期で検知すること**に価値がある（→§5の監視トリガー）。兆候は稼働の符号反転として現れ、それは年数予想より早く・確実に観測できる。

## 4. 戦略への含意（yah.homes）

1. **取得は前倒し**: ゴールドラッシュ期のうちに良い立地（六本松・大手門）を押さえる。行政確認・収支照合の優先度を上げる。競争は「集客」より先に「仕入れ」で始まっている。
2. **堀は需要エンジン**: 供給が倍増しても自社が92%稼働（市場73%・**+19pt**）なのは、外部需要注入（SEO/広告/多言語）とレビュー資産の効果。淘汰局面ではこの差が生死を分ける。設備差別化（洗面台数・浴室+シャワーブース・駐車場）は建売コンバートが後追いできない構造的な差。
3. **転換後は買い手に回る**: 稼働マイナス転換=撤退ではなく**モード切替（新築で建てる→弱った建売コンバートを安く買う）**。東京・札幌の下位帯が示すとおり、供給爆発の後には必ず売り物件が出る。
4. **自社の現在地は健全**: 市場平均売上$71.8Kに対し清川$82.8K（+15%）・市場ADR$306に対し週末≒$400で稼働92%。トップ帯を維持。
5. **9月・11月の運用**: 市場ワースト月=9月（清川9月苦戦は市場の形＝土曜¥55K判断を追認）。ベスト月=11月なのに自社11月は30〜50%——**10月の広告配分・価格で11月を取りに行く**。
6. **東京・札幌への横展開はしない**: 東京=供給爆発後期×取得費3〜4倍×180日規制、札幌=季節極端×空室型崩壊の初期。福岡の密度を上げる方が全指標で合理的。
