## カラーパレット（これ以外の色を使わない）

| 名称 | HEX | RGB | 用途 |
|---|---|---|---|
| Black | `#000000` | 0.0.0 | テキスト・ボタン・アクセント |
| White | `#FFFFFF` | 255.255.255 | 背景・ダーク面上のボタン/テキスト |
| Light Gray | `#F7F7F7` | 247.247.247 | セクション背景 |
| Gray | `#D7D7D7` | 215.215.215 | ボーダー・補助 |

- 🚨 **モノクローム4色のみ。青・赤・金などの差し色はパレット外**（旧サイトの LAMP_BLUE `#2B5BE8` / `#1a56db` は違反として2026-07に全廃済み）。
- ⚠️ **例外: 直販CTAボタンのみ CTA Blue `#1a56db` を正式採用（2026-08-16 発注者判断）。**
  詳細は下記「CTA色の例外規定」を参照。これ以外の面（テキスト・背景・ボーダー・装飾）に
  青を使ってはならない。
- 実装上、本文テキスト `#111111`・ボーダー `#e8e8e8` 等の近傍グレーは Black / Gray の運用値として許容（新規に増やさない）。

## 機能色の例外規定（2026-08-31 発注者判断）— 社内画面のみ

**社内の運用画面（yah.OS）に限り、状態を表す色をパレット適用外とする。**

| 意味 | HEX | 使う場所 |
|---|---|---|
| 正常・増加 | `#63d297` | 状態表示・前年比プラス |
| 要対応・減少 | `#ef4444`（文中は `#ff8080`） | 警告・前年比マイナス |
| 注意・保留 | `#e0b050` | 印・注記の帯 |
| 選択・強調 | `#6ea8fe` | フォーカス枠・選択中・グラフ |
| 状態ドット（正常） | `#3b82f6` | 左ナビのドットのみ |

### 条件（これを外れたら違反）

- **意味の表示だけに使う。装飾に使わない**（面の塗り分け・見出しの色付けは不可）
- **顧客が見る面には持ち込まない**——yah.homes・業者ポータル・送信メールの本文は
  モノクローム4色（＋直販CTAの例外）のまま
- 各意味につき**1色だけ**。増やすときはこの表に足してから使う
  （黄系が4種類に割れていた件は 2026-08-31 に `#e0b050` へ統一済み）

### 理由

yah.OS は運用画面で、「正常か・要対応か」を**色で瞬時に判別できないと機能しない**
（今日ボード・状態ドット・前年比）。モノクロの濃淡や記号では、一覧の中で危険を拾えない。
CTA Blue と同じく、**視認性を優先した限定的な例外**として正式に登録する。

### 適用範囲

os.yah.homes（認証必須の社内画面）のみ。ガイドラインの実装は
`yah-os/os.css` と `docs/design_guideline_yah_os_20260831.md`。

## CTA色の例外規定（2026-08-16 発注者判断）

**直販予約への導線となる CTA ボタンに限り、ブランドパレット適用外とし CTA Blue を用いる。**

| 用途 | HEX | 備考 |
|---|---|---|
| CTA Blue（通常） | `#1a56db` | 白文字とのコントラスト 6.18:1（WCAG AA 合格） |
| CTA Blue（hover） | `#1544b0` | |

### 経緯

- ナビの「予約する」ピルは長らく `#ff5a5f`（**Airbnb のブランド色**）だった。直販サイトの
  CTA が集客チャネルのブランド色である点と、白文字とのコントラストが **3.05:1 で
  WCAG AA 不合格**である点の2つの問題があった。
- 2026-08-16、CTA の色を検討。パレット準拠なら Black `#111111` が正解だが、
  発注者判断により **CTA ボタンはブランドガイドライン適用外**とし、視認性を優先して
  CTA Blue を採用した。
- `#1a56db` は 2026-07 に「パレット外」として全廃した色と同一。今回は上記の判断により
  **CTA ボタンに限って復活**させたものであり、規定の見落としではない。

### 適用範囲（ライト背景上の直販CTA）

| 箇所 | セレクタ |
|---|---|
| ナビの「予約する」ピル | `Navbar.astro` `.booknow-direct` |
| モバイルメニューの予約導線 | `Navbar.astro` `.mm-book-direct` |
| 物件カードの「公式サイトで予約（最安）」 | `home/PropertiesSection.astro` `.btn-direct` |
| 比較表の「Our site (best rate)」 | `home/ComparisonTable.astro` `.cmp-btn-direct` |
| ホームのインラインCTA | `home/InlineBookingCta.astro` |

### 適用しない箇所

- **ダーク背景・写真上の CTA は White ボタンのまま**（`PropertyDetail.astro` の
  `.pd-cta-direct` 等）。写真上では白が最も視認性が高く、青にする利点がないため。
- 直販以外のボタン（Airbnb/Booking.com への導線、ギャラリー、PDF等）は従来どおり
  Black / White を用いる。

## 写真のトーン

自然光・生活感のある「日常」のトーン（過度な加工をしない）。

## 運用ルール

- 新しい UI 色が必要になったら、まず上記4色（+運用グレー）で解決できないか検討する。できない場合はユーザーに相談（勝手にパレット外の色を足さない）。
- ダーク背景上のCTA: White ボタン + Black テキスト（例: `/booking` のAirbnbボタン、Locals のマップリストボタン）。
- ライト背景上のCTA: Black ボタン + White テキスト（例: ギャラリーボタン、PDFダウンロード）。
