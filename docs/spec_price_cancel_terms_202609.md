# 仕様書: 料金ボックスに無料キャンセル期限と「まだ課金されない」を出す

**作成**: 2026-09-03
**状態**: 承認待ち（未実装）
**対象**: `src/pages/[...locale]/book/index.astro` ／ `src/i18n/bookStrings.ts`
**規模**: 半日

---

## 1. 背景

実測（2026-08-04〜09-02・30日）で、**日程を確定した42人のうち決済画面に進んだのは14人（33%）**。3人に2人がここで離脱している。

現在の料金ボックスの表示:

```
總金額
¥120,000  已套用折扣
¥116,400
每人每晚 ¥14,550
約 NT$24,444
2晚 4人・含住宿費・住宿稅・清潔費
現場無需再支付任何費用。
官網預訂，日期變更與入住前的諮詢由我們直接為您處理。
[立即預訂]
```

**11万円を提示して「予約する」を押させるのに、「このボタンでは課金されない」とも「いつまで無料でキャンセルできる」とも書いていない。** キャンセル規定は決済ページまで進まないと出てこない（`co-cancel` / `co-trust-cancel`）。

金額の直後に不可逆な印象のボタンだけがある状態で、**離脱の説明として最も素直**。

---

## 2. 変更内容

料金ボックスの `[予約に進む]` の直前に2行を足す。

```
¥116,400
每人每晚 ¥14,550
約 NT$24,444
2晚 4人・含住宿費・住宿稅・清潔費
現場無需再支付任何費用。
──────────────────────────
✓ 2026年9月2日まで無料キャンセル      ← 追加
✓ このボタンではまだ課金されません      ← 追加
[立即預訂]
```

### 期限の計算

決済ページ（`checkout.astro` L479-482）と**同じ式をそのまま使う**。値がずれると信用を落とすため、実装をコピーする。

```js
// N日前の 00:00 JST = (N+1)日前の 23:59 JST。表記は後者に揃える（実質同じ期限）
const fcDays = house.freeCancelDays ?? 8;
const fc = new Date(Date.parse(`${state.checkin}T00:00:00+09:00`) - fcDays * 86400000);
const fcStr = new Date(fc.getTime() + 9 * 3600000).toISOString().slice(0, 10);
```

`freeCancelDays` は property_facts（`/admin/properties`）が正本。`book/index.astro` は既に `getPropertyFacts()` を読んでいるので、`HOUSES` に `freeCancelDays` を1項目足すだけで届く。

### 文言（`bookStrings.ts` に2キー追加・5言語）

| キー | ja | en | zh | ko | th |
|---|---|---|---|---|---|
| `freeCancelUntil(d)` | {d}まで無料キャンセル | Free cancellation until {d} | {d} 前可免費取消 | {d}까지 무료 취소 | ยกเลิกฟรีถึง {d} |
| `notChargedYet` | このボタンではまだ課金されません | You won't be charged yet | 點擊後尚不會扣款 | 아직 결제되지 않습니다 | ยังไม่มีการเรียกเก็บเงิน |

日付は既存の `fmtDate`（曜日つきロケール表記）を使う。

## 3. 検証

| # | 確認 | 期待 |
|---|---|---|
| 1 | 同じ日程で料金ボックスと決済ページを開く | **無料キャンセル日が完全に一致** |
| 2 | 5言語で表示 | 文字化け・はみ出しなし |
| 3 | 満室の日 | 追加した2行は出ない（料金ボックス自体が出ないため） |
| 4 | `/admin/properties` で `freeCancelDays` を変更 | 両画面とも追従する |

**判定（2週間後）**: `dates_selected → checkout_viewed` が現在の33%から上がるか。母数は月42人なので、2週間で20人前後。**大きな変化しか見えない**ことは承知の上で見る。

---

## 4. やらないこと

- **料金の内訳開示**（宿泊費・清掃費¥15,000・税の分解）— 清掃費を明示すると1泊予約の割高感が出る諸刃。本件の結果を見てから判断する
- **ボタン文言の変更** — 同時に変えると、どちらが効いたか分からなくなる

---

## 5. リスクと巻き戻し

| リスク | 対策 |
|---|---|
| 決済ページと日付がずれる | §3-①で必ず突き合わせる。式をコピーしているのでずれる場合は両方の不具合 |
| 「課金されない」が誤解を生む | 決済ページでは実際に課金されるため、文言は「このボタンでは」と限定する |

**巻き戻し**: 表示の追加のみ。`git revert` で即座に戻る。
