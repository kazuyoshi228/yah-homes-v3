# 出口の器と個人系の切り離し（v1・2026-08-19）

前提: [strategy_yah_os_exit_v1.md](strategy_yah_os_exit_v1.md)。本メモはその中の
「どの器で売るか」に絞った検討。**状態: 方針決定済み・実務は未着手。**

## 決めたこと

**器はボンファイア株式会社のまま維持する。会社は分けない。**
そのうえで、宿泊事業に属さない個人系を外していく。

理由は許認可と契約の断絶を避けるため。会社を分けたり事業だけを譲渡すると、
旅館業の営業許可を取り直すことになり、その間は営業できない。
買主から見れば「引き継いだ瞬間にNOIが途切れる」ので、収益還元では評価されない。

## なぜこの判断が金額に効くか

清川の2046年時点の評価を2つの方法で出すと、こう割れる。

| | |
|---|---|
| 積算（土地＋建物残存） | 0.65億 |
| 収益還元（NOI÷5%） | 1.93億 |
| 差 | **1.28億** |

木造の建物価値は22年でゼロになるため、積算は20年間ほぼ横ばい（0.69億→0.65億）。
一方、稼働が続いていればNOIはインフレ2%で伸びるので収益還元は上がる。
**この1.28億は「事業として回っていること」の値段であり、不動産の値段ではない。**

方式によって、この1.28億が取れるかが変わる。

| | 事業譲渡 | 株式譲渡 | 会社分割＋株式譲渡 |
|---|---|---|---|
| 旅館業許可 | **承継されない** | 維持される | 要確認 |
| 契約（運営委託・業者） | 相手方の同意が要る | そのまま | そのまま |
| OTAのレビュー・アカウント | 移らない | 残る | 残る |
| 買主の簿外債務リスク | なし | あり（DDが厳しい） | 小さい |
| 不要な資産を置いていけるか | できる | 付いてくる | 切り離せる |
| **1.28億が取れるか** | 難しい | **取りやすい** | 取りやすい |

株式譲渡を選ぶ代わりに、買主は簿外債務のリスクを負う。だからDDが厳しくなる。
**根拠の揃った数字を用意しておくことが、そのまま値段になる。**

## 個人借入 9,000万の扱い（急いで返すべきではない）

2.0%固定・20年。インフレ2%が続くなら**実質金利はほぼゼロ**で、
時間が経つほど実質負担が軽くなる。**繰上返済は、価値が目減りしていくはずだった
債務を、価値が高いうちに返す行為**になるので不利。

ただし株式譲渡では債務が新オーナーに引き継がれる。親族への債務が2047年まで
残っている状態で株式を売れるのか、譲渡代金から返済するのか、資本に振り替えるのか。
**税務と資金繰りの両面で設計が要る。税理士に相談する事項。**

## 分離の実務は「法人を分ける」ではなく「部門を使う」

MFクラウド会計の仕訳に `借方部門` `貸方部門` の列があり、**全行が空欄**。
ここに `清川` `高砂` `大手門` `六本松` `全社` `千人町` を入れるだけで、
**法人は1つのまま、部門別の損益計算書が出る。**

法人を分けると許認可の取り直し・口座の作り直し・契約の巻き直しが発生する。
部門なら設定するだけで明日から使える。そして将来、会社分割を選ぶ場合も
「どの資産・負債・契約が宿泊事業に属するか」の特定が数日で終わる。
付いていなければ数年分の仕訳を1件ずつ判定することになる。

過去分は遡らない。**1年後には12ヶ月分の部門別PLが揃う。**

## いま確認すべき3つ

1. **福岡市（保健所 生活衛生課）に、会社分割時の旅館業許可の扱いを聞く。**
   承継できるか、新規取得が必要か。電話1本で分かる。これで出口の設計が決まる。
2. **AIRSTARとの運営委託契約に譲渡制限があるか。** 契約書を見れば分かる。
3. **個人借入 9,000万の扱いを税理士に相談する。** 株式譲渡と事業譲渡では課税が
   大きく変わる（株式譲渡益は分離課税、事業譲渡は法人税＋消費税）。
   手取りが数千万円変わるため、方式を決める前に試算しておく。

## 本メモの限界

許認可の承継可否・税務の具体的な扱い・契約の解釈は専門家の領域。
本メモが示すのは「何が論点か」と「誰に何を聞くか」までとする。
