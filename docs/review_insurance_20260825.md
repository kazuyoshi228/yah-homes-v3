## 1. 結論 — 削るなら「盗難」ではなく「高砂の火災保険」

### ご指摘の「盗難」は、削っても効果がほぼ無い

GK すまいの保険で盗難は**建物の補償**に含まれる事故の一種で、**単独の特約ではない**。
外すには補償範囲の狭いプラン（フルサポート → 基本など）へ落とすことになり、
そのとき**水災も一緒に落ちる可能性がある**。

さらに、**民泊で盗難を外すのは筋が悪い**:
- 不特定の他人が毎日出入りする（一般住宅より事故率が高い）
- GKの盗難免責は**0円**＝小さな被害でも使える
- 「防犯対策費用特約」（再発防止の費用・機器20万/ドアロック10万）とセットで、
  鍵交換が必要になったときに効く

**盗難を外して浮く額は、プラン全体を落とさない限りほぼゼロ。** 削る先として不適当。

### 本当の削りどころ ①: 高砂の火災保険が清川の2.3倍

| | 清川 | 高砂 |
|---|---:|---:|
| 建物保険金額 | 2,100万円 | **2,482万円** |
| 保険料（建物） | ¥42,430 | **¥112,800** |
| 地震保険 | ¥10,610 | ¥12,530 |
| 築年 | 令和6年（2024） | **平成23年（2011）** |
| 破損・汚損の免責 | 1万円 | **0万円** |
| 地震火災費用 | 保険金額×5%（300万限度） | **×50%（限度なし）** |

保険金額の差は18%なのに、**建物の保険料は2.7倍**。理由は築13年差の建築年割引と、
**補償の手厚さ（免責0円・地震火災費用50%）**。

**見直しの余地が最も大きいのはここ。** 具体的には:
- **破損・汚損の免責を 0万 → 5万** に上げる（清川は1万）。
  数万円の傷を保険で直すことは実務上ほぼ無く、等級・事故歴の面でも使わない
- **地震火災費用 50% → 5%** へ（清川と同条件）。地震保険本体（1,241万円）は残す

概算で **年2〜4万円**の圧縮余地。※実額は代理店見積が要る

### 本当の削りどころ ②: 水災ランク3の再確認

両棟とも**水災ランク3**で、水災の免責は**5万円**。清川は那珂川が北東40m、
重説では洪水1.0〜2.0m・家屋倒壊等氾濫想定区域に近接。

**水災は絶対に外さない**（ご指摘のとおり）。むしろ**免責5万→0万への引き上げ**を
検討する価値がある——床上浸水は数百万規模で、5万の免責より保険料増のほうが安い可能性。
見積で比較したい。

## 2. ビジネスキーパー（賠償）は削れない

2棟で年¥159,950。中身は**民泊の生命線**:

| 補償 | なぜ要るか |
|---|---|
| 借家人賠償責任・修理費用 | ゲストが設備を壊した／火を出した |
| **賠償責任等** | **ゲストが施設内で怪我をした（民泊で最も重い）** |
| 受託物賠償 | 預かった荷物の破損 |
| 弁護士費用 | 近隣トラブル・訴訟 |
| 敷地内屋外物件包括 | 門塀・外構 |
| 業務用現金盗難 | — |
| データ損害 | 宿泊者名簿（法定3年保管）の消失 |

**ゲストの怪我1件で数百万〜。** 年16万は保険としてむしろ安い。ここを削るのは
「事業をやめる」に近い判断になる。

**ただし1点、重複の疑いがある**: GK側にも「類焼損害・失火見舞費用」があり、
BK側の「事業者用類焼損害補償」と重なる可能性。**代理店に確認する価値あり**（年880円だが）。

## 3. 削減の順（推奨）

| # | 打ち手 | 見込み | 難度 |
|---|---|---:|---|
| 1 | **高砂GKの免責引き上げ**（破損汚損0→5万） | 年1〜2万 | 更改時に伝えるだけ |
| 2 | **高砂GKの地震火災費用を50%→5%**（清川と同条件） | 年1〜2万 | 同上 |
| 3 | 類焼損害の重複を確認（GK×BK） | 年880円 | 質問1つ |
| 4 | **相見積もり**（他社・同条件で） | 年3〜5万？ | 手間あり |
| 5 | 水災免責 5万→0万の**増額**を検討 | **マイナス**（増える） | 要判断 |

**1〜3で年2〜4万円。** 4を入れれば更に。

**4の相見積もりが本命**かもしれない。4本すべて三井住友海上・BrightReach1社に
集中しており、比較したことがない状態。ただし**代理店を替えると事故対応の窓口も替わる**ため、
金額だけで決めない。
