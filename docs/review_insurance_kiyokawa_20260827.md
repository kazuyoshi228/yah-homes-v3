## 2. 各項目の中身

### 1. 休業損害（最優先）

見積書の休業損害欄（約定復旧期間・口数）が**空欄に見える**。未付帯なら、火災等で営業できない間の
**逸失利益は1円も出ない**。

- 清川の売上は年約1,495万＝**月約124万**
- 半年止まれば**約750万**の逸失

保険料を削る話より先に、**これが付いているかを確認する**。付いていなければ付ける。

> 補足: BKの休業損害は**財物事故が原因の休業**が対象。感染症で保健所に止められた休業は出ない。
> そちらは旅館賠償のオプション（食中毒・特定感染症利益補償特約）が受け皿になる（§1-5）。

### 2. 設備什器 400万 → **据え置き（決定・2026-08-27 発注者）**

設備台帳の**動産合計 ¥7,021,150**（家具338万・設備260万・建材41万・カーテン34万・装飾20万・照明8万）
に対して保険金額は400万。**差は302万**。

- ★**新価実損払特約が付いている**ため、一部保険による比例減額（80%ルール）は働かない。
  400万は「割合」ではなく**ハードな上限**。400万までは満額出て、超えた分が自腹
- ただし建物に固定された設備（給湯器・24時間換気・システムキッチン等）は
  **GK側の建物2,100万に含まれる可能性**があり、線引き次第で不足額は変わる
- 700万への引き上げ試算: **¥96,595（+¥18,255／年）**

→ **【決定】400万のまま据え置く（2026-08-27 発注者）。差の302万は自己負担とする。**
新価実損払なので400万までは満額出る。全損時に302万が自腹になることを承知のうえでの選択。
**動産が増えたら再検討する** — 設備台帳の合計が増えたときが見直しの合図。

### 3. 電気的・機械的事故（⑨）

いまのBKは**ワイド**で、**⑨電気的・機械的事故が対象外**。エアコン4台・給湯器・洗濯乾燥機の
**内部故障は出ない**。手段が2つある:

| 手段 | 中身 | 免責 |
|---|---|---|
| BK を**ワイドPlus** に上げる | ①〜⑩すべて | ⑨は3/5/10/20/50/100万から選択（標準3万） |
| GK の**建物電気的・機械的事故特約** | 建物設備の電気的故障 | 5万固定 |

対象範囲が違う（BKは什器・動産側、GKは建物設備側）ので、**どちらが安いかだけでなく
どちらに何が入るか**を代理店に整理してもらう。

### 4. 賠償の支払限度額（証券が伏字）

BKの `賠償責任等補償` `受託物賠償責任補償` の**支払限度額が証券で伏字**になっており不明。

**限度額が分からないまま削減の交渉をしない。** ゲストの怪我1件で数千万規模になり得るため、
まず限度額を出してもらう。旅館賠償（§1-5）と重なる部分の整理も、この数字が無いと決められない。

### 5. 旅館賠償責任保険・旅館宿泊者賠償責任保険（新規）

**旅館業許可あり**（2026-08-27 発注者確認）のため引受可。詳細は
`spec_ryokan_liability_20260827.md`。要点だけ:

- **埋まる穴は2つ** — ①館内でゲストの所持品が盗まれた ②**ゲストが加害者**の事故（ゲスト間）
- ①③はBKの賠償・受託物賠償と**重なる**。限度額の高いほうへ寄せて低いほうを薄くする（§1-4が前提）
- **生産物危険条項を外すと食中毒・特定感染症の特約が付けられない**。この2つはセットで判断する
- 見積条件は作成済み。**送信前に許可証の定員が要る**

### 6. 免責の引き上げ（方針決定済み・2026-08-25 発注者）

| | いま | 打診 |
|---|---|---|
| BK 破損・汚損等 | 3万 | **5万** |
| GK 破損・汚損 | 1万 | **5万** |

5万未満は自腹で構わない、という判断。

> ★GKは**免責を0・1・3万に設定しても、水ぬれと破損汚損には自動で5万が適用される**。
> つまりGK側は**すでに実質5万**で、1万→5万の変更で保険料が下がるかは確認が要る。
> 「下がらないなら現状のまま」でよい。

### 7. 屋外設備・庭木の限度 — **不要と決着（2026-08-27 発注者確認）**

GKでは屋外設備（井戸・側溝・敷石等）と庭木も建物に含まれるが、
**1事故につき敷地内一括で合計100万円が限度**。

**清川には屋外設備（井戸・側溝・敷石等）も庭木も該当なし**（2026-08-27 発注者確認）。
100万の限度に当たる資産が無いため、**屋外明記物件特約は検討しない**。

> 車庫は**延床66㎡未満の付属建物**としてGKの建物に自動で含まれる。屋外設備の枠ではない。
> 植栽メンテは定期で入れているが、保険の対象となる資産の話とは別。

### 8. 建物2,100万の妥当性

#### 先に整理 — 「半額しか出ない」のは地震だけ

| | 保険金額 | 上限 |
|---|---|---|
| 火災・風災・水災など | 建物 **2,100万** | 2,100万まで**満額** |
| 地震・噴火・津波 | 地震保険 **1,050万** | **建物の50%が上限** |

地震保険が半額なのは契約が薄いからではなく、**法令で「火災保険金額の30〜50%」と定められている**ため。
1,050万は**上限いっぱい**で、これ以上は積めない。

さらに地震保険は実損払いではなく**区分払い**（全損100%／大半損60%／小半損30%／一部損5%）。
**全損認定で初めて1,050万**が出る。

- 火災で全焼 → **2,100万**（建物金額が足りていれば満額）
- 地震で全壊 → **1,050万**。残り半分は自己資金

埋める手段は**地震危険等上乗せ特約**（地震保険と合わせて100%にするもの）しかない。
三井住友海上に該当商品があるかを代理店に確認する（§4-10）。

#### 本題 — 火災側を **2,500万へ引き上げる（方針決定・2026-08-27 発注者）**

2,500万＝**24.2万/㎡**（専有103.28㎡）。新築の再調達水準として妥当。

概算（現行の内訳を金額比例で伸ばしたもの・**要代理店確認**）:

| | 2,100万 | **2,500万** |
|---|---|---|
| 建物 | 42,430 | **50,512** |
| 地震 | 10,610 | **12,631** |
| 類焼 | 880 | 880（据置） |
| **合計** | **¥53,920** | **約¥64,020**（+約¥10,100／年） |

**地震保険金額も 1,050万→1,250万 に連動して上がる**（火災保険金額の50%が上限のため）。
半額しか出ないという構造は変わらないが、**その半額の絶対額が増える**。

★制約: GKの建物保険金額は**標準評価額の±30%**の範囲。
いまの2,100万が範囲のどこにあるかが未確認で、**既に上限側なら2,500万は取れない**。
その場合は**個別評価**（工事請負契約書の写し）を根拠に出す。
仕訳帳の工事費は把握済み（`properties/kiyokawa.constructionSource`）で、根拠資料は出せる。


- 清川・高砂とも **¥/㎡ で見ると約20万/㎡**。以前「高砂が過大では」と見たのは誤りで、
  **むしろ両方とも低い可能性**がある
- GKの建物保険金額は**標準評価額の±30%**の範囲で設定する。いまが範囲のどこにあるかを確認する
- 個別評価（工事請負契約書の写し）を出せば、その額を上限にできる
  → **六本松は請負金額で設定できる**（新棟の強み）

## 3. 決まっていること（交渉の前提・2026-08-25 発注者決定）

| | 決定 | 理由 |
|---|---|---|
| 相見積もり | **不要** | BrightReach／三井住友海上を継続する |

**削る方向の余地は免責だけ**、というのが現在の結論。残りは**足りているかを確かめる**作業。

## 4. 代理店へ聞くこと（1通にまとめる）

1. **休業損害**は付帯されているか。未付帯なら付帯した場合の保険料（§2-1）
2. 建物に固定された設備（給湯器・24時間換気・システムキッチン等）は
   **GKの建物とBKの設備什器のどちらに入るか**（§2-2）
3. ~~設備什器 400万→700万 の差額~~ → **据え置き決定のため取り下げ（2026-08-27）**
4. **BKワイドPlus** と **GK建物電気的・機械的事故特約** の対象範囲と保険料差（§2-3）
5. BKの **賠償責任等・受託物賠償の支払限度額**（証券が伏字・§2-4）
6. GKの免責 **1万→5万** で保険料が下がるか（水ぬれ・破損汚損は自動5万のため・§2-6）
7. **建物を2,100万→2,500万に引き上げたい**（§2-8）。標準評価額の±30%に収まるか。
   収まらない場合は**個別評価**（工事請負契約書の写しを提出）で可能か。保険料もあわせて
10. **地震危険等上乗せ特約**（地震保険と合わせて100%にする）の取扱いがあるか・保険料（§2-8）
11. 旅館賠償・旅館宿泊者賠償の見積（別紙・`spec_ryokan_liability_20260827.md` §6の条件）
