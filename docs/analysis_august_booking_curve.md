## 4. 運用への含意

1. **月初の確保率が着地をほぼ決める。** 経験則として「月初の確保率 + 10pt ≒ 着地」。9月は9/1時点で約58%だったので、この式なら着地は65〜70%。介入するなら月初より前（＝2ヶ月前）に打つのが正しい
2. **したがって注視すべきは常に「翌々月」。** 週次スコアカードの3ヶ月稼働率カードで、当月ではなく**次々月**が50%を割っていないかを見る
3. **経路は依然Airbnb一極**（53泊 vs Booking.com 1泊）。直販は8月宿泊分ではゼロ（直販1号は9/10宿泊）。この集中は9月以降どう変わるかを同じ手法で追う価値がある
