# 依頼: Beds24 の販売期間を延長してください（2027年5月以降が売れていません）

**作成**: 2026-08-20
**宛先**: 運営会社（Airstar）／Beds24 設定担当
**緊急度**: 中〜高（機会損失が既に発生しています）

---

## 何が起きているか

**2027年5月1日以降、清川・高砂とも在庫がまったく開いていません。**

Beds24 の在庫カレンダーを確認したところ、こうなっています。

| 月 | 清川（販売中/閉） | 高砂（販売中/閉） |
|---|---|---|
| 2027-03 | 31日 / 0日 | 28日 / 0日 |
| 2027-04 | 30日 / 0日 | 27日 / 0日 |
| **2027-05** | **0日 / 31日** | **0日 / 31日** |
| **2027-06** | **0日 / 28日** | **0日 / 30日** |
| **2027-07** | **0日 / 31日** | **0日 / 31日** |

予約が入っているわけではなく、**販売していない**状態です。境界は **2027年4月30日**（本日から約8.5ヶ月先）。

## 実害が出ています

- 直販サイトで **2027年5月の空室照会が2件**ありました（2026-08-19〜20 の2日間）。この方々には「満室」と表示され、そのまま離脱しています。
- Beds24 はチャネルマネージャーなので、**Airbnb・Booking.com でも同様に売れていない**と考えられます。直販だけの問題ではありません。

## なぜ今なのか（リードタイムの実測）

自社の予約実績（311件）を分析した結果:

- 全予約の **21% が到着90日以上前**
- 冬期（12〜2月着）は中央値56日・**最長240日前**の予約あり
- 2027年5月は**本日から約253日先**。すでに問い合わせが来る時期に入っています

2027年のゴールデンウィーク（5月上旬）は、グループ・家族旅行の最需要期です。ここを売っていないのは大きな取りこぼしです。

## お願いしたいこと

**Beds24 の在庫公開期間を、少なくとも「今日から12ヶ月先」まで延長してください。**

確認箇所（Beds24 管理画面）:
- Settings → Properties → 各物件 → **Booking Rules**（または Availability）
- 「**Max advance booking**」「Booking window」などの項目
- あわせて、在庫カレンダーが該当期間まで生成されているかもご確認ください

清川・高砂の**両方**が対象です。

## 補足（設定変更のついでにご確認いただきたい点）

現在の料金・最低宿泊日数の設定は、確認した範囲では正常でした。

- 最低宿泊日数: 1泊（金土2泊ミニマムは別途設定されている想定）
- 料金: 平日¥40,000／金土¥60,000 が2027年4月まで設定済み

**5月以降を開放する際は、料金の設定漏れがないかもご確認ください。** 在庫だけ開いて料金が未設定だと、別の問題が起きます。
