## 1. なぜ韓国 × Meta なのか（実測の根拠）

### ① 韓国は既に最大の顧客層

開業〜2026-08 の実測（311組・国籍別）:

| 国 | 組数 | 平均泊数 | 1予約の売上 | 1予約の貢献利益 |
|---|---|---|---|---|
| **韓国** | **90（1位）** | 2.17 | ¥114,833 | ¥62,383 |
| 台湾 | 52 | 3.06 | ¥162,058 | ¥95,440 |
| 香港 | 27 | 2.81 | ¥149,185 | — |

**マーケティングを一切していない状態で、組数1位。** 累計の貢献利益でも韓国が最大（約¥561万 vs 台湾¥496万）。

### ② Google広告では届かない（3段で証明済み）

2026-07 の実測: 広告表示2回／キーワードプランナーで독채系はデータなし・후쿠오카 숙소は月260でYoY−76%／全KW有効なのに配信されない。**Google韓国に宿検索の在庫が存在しない。**

「韓国は捨てる」という過去の判断は**Google広告についての判断**であり、韓国市場そのものの評価ではない。ここは混同しやすいので明記する。

### ③ Instagram経由の流入は質が高い（サンプル小）

28日実測: `l.instagram.com` から10人来訪 → **8人が手渡し（80%）**。Google広告（779人→232人・30%）の2.7倍。
さらにIG流入のランディング先は **`/ko` が4人で最多**（`/zh` 6人・`/ja` 1人）。**韓国はIGで既に来ている。**

### ④ 6月のMeta広告は「目標設定を誤った」だけ

¥101,300を投下し、プロフィール訪問6,816件（¥14.9/件）・フォロー218人を獲得。しかし目標が「プロフィールへのアクセス」だったため、サイトには漏れ出た348人しか来ていない（実効CPC ¥291）。**媒体が悪いのではなく、目標と着地先が無かった。** 現在は5言語のサイトと直販予約が稼働している。

## 2. 仮説と目的

**仮説**: 韓国の訪日グループ客はGoogle検索ではなくInstagramで宿を探しており、Meta広告で直接リーチできる。

**目的**: 韓国からの流入を「OTAの自然流入頼み」から「制御可能なチャネル」に変える。副次的に、新棟オープン時の立ち上げ加速手段を得る。

**これは10棟構想の主エンジンではない**（10棟に必要な年1,335組のうち大半はOTA自然流入が運ぶ）。位置づけは**加速装置とチャネル分散**。

## 3. キャンペーン設計

| 項目 | 設定 |
|---|---|
| 目的 | **トラフィック（ウェブサイトへのアクセス）** ※プロフィールへのアクセスにしない |
| 予算 | **¥1,000/日 × 14日 = ¥14,000** |
| 地域 | 韓国 |
| 年齢 | 25〜45歳 |
| 興味関心 | 日本旅行 / 海外旅行 / Airbnb / 福岡・九州 |
| 配置 | 自動（Reels・フィード・ストーリーズ） |
| 遷移先 | `https://yah.homes/ko/?utm_source=ig&utm_medium=paid&utm_campaign=kr` |
| 除外 | ピクセルの `purchase` 到達者（予約済みに広告を出さない） |

### クリエイティブ

**リールを主軸にする**（静止画は非フォロワーにほぼ届かない）。既存のリール資産を流用可。

訴求の軸（韓国市場向け・実測データに基づく）:
1. **독채（一棟貸し）で1日1組** — 韓国語の必須語彙。ホテルとの違いが一言で伝わる
2. **6〜7명이 한 채에**（6〜7人が1軒に） — グループ旅行の解決
3. **1인 1침대**（1人1ベッド・高砂） — オーナー承認済みの訴求
4. **공항에서 시내 5분**（空港から市内が近い） — 2泊3日の短期旅程に効く

※ 韓国客の平均は2.17泊。**長期滞在を前面に出さない**（台湾向けの「連泊」訴求は転用しない）。

## 4. 判定基準（2週間・¥14,000）

| 指標 | 合格ライン | 根拠 |
|---|---|---|
| CPC | **¥150以下** | 6月の実効¥291は目標設定ミス。プロフィール訪問が¥15で買える媒体なので、リンククリックは¥50〜150が想定 |
| 手渡し率 | **20%以上** | Google広告30%・IG自然流入80%の間。広告経由は冷たいので20%を合格とする |
| 直販CV | 参考値 | 2週で0〜1件の想定。判断材料にはしない |

**ROASの損益分岐は 8.8倍**（満室時＝Airbnbからの付け替え）。ただし2週間では母数不足のため、この期間はCPCと手渡し率で判定する。

### 中止条件
- CPC ¥250超が1週間続く → 目標設定かクリエイティブの問題。停止して見直す
- 手渡し率10%未満 → 遷移先（`/ko/`）かターゲットが合っていない

## 5. 前提条件（着手前に必要）

- [x] Metaピクセル設置（2026-08-16 デプロイ済・ID 2216414819216704）
- [x] プライバシーポリシーへのMeta記載（5言語・反映済）
- [ ] **ピクセルのデータ蓄積を1〜2週間待つ**（除外オーディエンス「purchase到達者」を機能させるため）
- [ ] Instagram のbioリンクに `?utm_source=ig&utm_medium=bio` を付与（自然流入と広告流入の分離）
- [ ] リール素材の確認（韓国語キャプション・字幕）

---

## 6. やらないこと

- **自動詳細マッチングはオフのまま** — 氏名・メール等をMetaに送る機能。オンにするならプライバシーポリシーの再改定が必要
- **Conversions API（サーバー側 purchase 送信）は今回のスコープ外** — 直販CVが月30件を超えてから
- **KOL募集の広告は出さない** — KOLは案件を検索しない。bioリンクとプラットフォーム登録で足りる
- **予算の追加は判定後** — 2週間は¥1,000/日を動かさない（学習を安定させる）

## 7. リスクと留意点

| リスク | 対応 |
|---|---|
| 韓国客は平均2.17泊と短く、清掃¥15,000が固定でかかるため1予約の利益率が低い（貢献利益¥62,383・台湾の65%） | 量で取る市場と割り切る。最低宿泊日数の設定は別途検討 |
| Google広告と違い検索意図がないため、冷たい流入になる | 判定ラインを手渡し率20%と低めに設定済み |
| 既にOTA経由で来ている韓国客を、広告費を払って取り直すだけ（カニバリ）の可能性 | 増分効果は測定不能。**満室期は基準ROAS 8.8倍、空室期は緩める**という原則で運用 |
| プラットフォームを1つ増やす運用負荷 | 2週間の期間限定テストとして開始し、合格しなければ畳む |

## 8. 成功時の展開

判定に合格した場合の次段階（本仕様のスコープ外・別途判断）:
1. 予算を¥2,000/日へ（月¥6万）
2. リターゲティング（サイト訪問者・カート離脱者）を追加 — ピクセルのデータが溜まってから
3. 台湾・香港へ同じ設計を横展開（Google広告と併走させ、チャネル別の効きを比較）
4. 新棟オープン時の立ち上げブーストに組み込む
