### 1. insurance.html（保険の見直し）——優先度: 高　**済（2026-08-27・ツールスレッド）**

試算の係数がコードに焼き込まれている。**これは例示ではなく事業の係数**＝assumptions 行き。

| 行 | 中身 | 処置 |
|---|---|---|

実施メモ（2026-08-27）: フォールバック値はコードに置かず、係数が読めないときは試算UIを畳んで理由を表示する方式にした。
`grep -c '20.2|53,920|78,340|60.85|54000' insurance.html` = 0 を確認。

assumptions スキーマ（他の係数と同じ流儀・人の判断のみが書く）:
```
assumptions/insurance-units:
  { label: "保険試算の単価", baseUnit: 20.2, ageRate: 0.075, eqUnit: 10.1, bkGoodsUnit: 60.85,
    basis: "清川2026実績（建物2,100万・年¥53,920 ほか）から逆算", updatedAt: "..." }
```
画面は `api` 経由で読み、**取れない時は試算UIを畳む**（フォールバック値をコードに残すと二重管理に戻る）。

## 再発防止（共有部・実施済みの宣言）

新規カードの雛形時代に同じ焼き込みが再発しやすい。共有部スレッドが CLAUDE.md に一行追記済みの原則:
**「HTMLに実在の金額・係数を書かない。書いてよいのは『例:』付きの例え話とコード注釈だけ」**。
