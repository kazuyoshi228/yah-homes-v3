## 2. 画面（4つのセクション）

### ① 一覧（横並び）
棟 × 商品で、年額・保険金額・免責・主な特約・満期・状態（見積/証券）を1つの表に。
**単価（保険料÷保険金額）の列**を出す——ここが見直しの入口になる。

### ② 更改カレンダー
```
2027-01-09  清川（GK・ビジネスキーパー）  ← 4ヶ月後
2027-03-14  高砂（GK・ビジネスキーパー）
```
既存の定期作業（`schedules`・GKすまいの保険の更改）と同じ日付を映すだけ。二重に持たない。

### ③ 更改の方針（決定済み・2026-08-25）
`insurance` のメモに入っている①〜⑤をそのまま出す。次の更改で迷わないため:
1. 免責の引き上げ: 破損・汚損 0万→5万（5万未満は自腹で構わない）
2. 相見積もり: 不要。BrightReach／三井住友海上を継続
3. 水災: 下げない。免責も現状維持（清川は那珂川40m・洪水1.0〜2.0m想定区域）
4. 盗難: 外さない（プランごと落ちて水災まで下がるため）
5. 賠償（ビジネスキーパー）: 継続

### ④ 新棟の見積依頼（六本松・大手門）
**清川の条件を雛形として出す。** 新築・H構造・ホテル/旅館(イ) が同じなので、
清川の内容（建物2,100万＋地震1,050万・フルサポート＋ビジネスキーパー ワイド）を
そのまま渡せば、代理店が見積もりやすい。

画面には「六本松の見積依頼（清川と同条件）」として、
**建物金額だけ差し替える欄**と、コピーできる依頼文を置く。
