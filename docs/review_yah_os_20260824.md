## 維持すべき強み（触らない）

1. **保存しない勇気。** 派生値を持たない規律が、今日の上限変更（20→30年）を1箇所の編集で14件に波及させた
2. **監査を画面に出す。** 監査 ✓12/12 バッジと突合⚠は、信頼を「点検した記憶」から「見れば分かる状態」に変えている
3. **fail-closed。** 業者未定はAIが動かない。無効19件は欠陥ではなく設計
4. **根拠つきの数字。** 図面実寸→内訳6行→出典明記の連鎖。見積が来たら実額に置き換わる前提も正しい

## 経営の視点からの一言

このOSの本質は帳簿ではなく**判断の前倒し装置**。2036年の¥132万も、12/31の料率判断も、既にデータとしては掴んでいる。掴んだものを**朝一番の画面に出す**のがP1で、投資対効果は全提案中で最大。逆に、機能追加（新カード）は当面不要——器は足りている。埋めるべきは高砂のデータと、画面の「今日性」。
