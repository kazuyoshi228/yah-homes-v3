## 0. 事業の肝（発注者テーゼ・2026-08-19）

**「24H/365で事業が回っていく。売上がサブスク的に立つ。資本価値が高まっていく。」**

1. **24H/365** — エージェント群（chat・メール・手配AI・周期エンジン）が営業時間なしで事業を回す
2. **サブスク的な売上** — 獲得ファネルが自動で予約を流し込み、**先付け予約残高がMRR/受注残に相当**
   （宿泊業をフォワードブックで語れる。将来のFCで本物のARRが上乗せ）
3. **資本価値への転写** — キャッシュフローが毎月、返済（残債減）と収益還元（NOI↑→評価額↑）の
   二経路でB/Sに積み上がる。財務3カード（財務・融資の返済・土地の評価額）はこの転写の計器

一行で: **エージェントが24時間事業を回し、売上が自動で積み上がり、毎月資本価値に転写される。
人間の仕事は週15分の決裁。** — これがエクイティストーリーの第一文。

## 2. 価値の設計図: 三階建て

```
③ オプション価値 …… FC/OS外販の「開ける権利」（ARR×7〜10倍の潜在）
② 事業価値(P/L) …… 自社棟EBITDA × 5〜8倍
① 資産価値(B/S) …… 保有不動産の評価額 − 残債（NAV）＝下値の保証
```

- ①②は失敗しても残る土台。③は資本ゼロで開く上値。
- **はずみ車**: yah.OSがNOIを上げる → 収益還元で評価額が上がる（含み益はOSが作る）
  → 担保余力(LTV)が生まれる → 次の棟を取得 → OSに載せて定常0分で稼働 → NOIが上がる…
- 当ての到達イメージ（10年レンジ）: 本体＋ファンド計100〜170棟、
  エクイティ価値 = NAV ＋ EBITDA×倍率 ＋ FCオプション ≒ **80〜120億**。
  自社30棟のみなら約40億（それでも下値として機能する）。

## 3. 資本政策: 二層バランスシート

- **コア層（本体・無希釈）**: 30棟を上限目安に本体で絶対保有。ブランドの本丸・下値40億の土台。
- **ファンド層（31棟目〜）**: SPC/私募ファンドで取得。LP=外部資本、yah.=GP出資10〜20%＋
  キャリー20%＋ブランド・OSフィー。**所有は共有、ブランドと運営はyah.**。
- 株式での大型調達はNAVディスカウントを受けやすく非効率。負債・LP資本を主とする。
- 調達条件を決めるのは yah.OS の実証データ（§7）。データが利率を下げ、キャリーを厚くする。

### 3-2. 金融商品化（ファンド層の完成形・D6）

規格化されたエンスイート戸建て（§4-2）は、**個別性の強い不動産ではなく「同一仕様・実測キャッシュ
フロー付きの量産資産」**になる。これが金融商品化の前提条件（証券化は規格品にしか効かない）。

1. **段階1: 私募ファンド/SPC**（§3の二層バランスシートのファンド層そのもの）
2. **段階2: 不特法の小口化商品** — 1棟5,000万〜1.2億を一口数十〜数百万に分割し、
   個人投資家へ。「yah.OSが運営する実物資産＋実測利回り」は小口化と相性が良い
3. **段階3: 出口の多様化** — 規格棟のポートフォリオはREIT・機関投資家への一括売却が可能になる。
   100億の出口は「会社を売る」だけでなく「**資産プールを金融市場に売る**」道が開く
- 商品性の裏付けは全てOSが供給する: 月次実測レポート（自動化Phase 2）・human-minutes・
  変換レート・稼働の時系列。**開示資料が自動で生成される金融商品**は、それ自体が差別化になる。

## 4. 仕込み戦略: 都市部の二刀流

| | 新築（清川・高砂型） | 都市部空き家コンバート |
|---|---|---|
| 投下/棟（当て） | 1.2億 | 0.5〜0.8億（古家付き土地＋改修1,000〜2,000万） |
| B/S | ◎ 土地が上がる | ◎ 土地値は残る |
| P/L | 中 | 高（投下が小さい） |
| 供給 | 土地待ち | **相続・古家付き土地に大量に眠る**（空き家の過半は都市圏） |

- 空き家は「安いから買う」を禁止。**需要フィルタを通った空き家だけ買う**（§5の判定OS）。
- 三悪を機械的に落とす: 旧耐震（改修上振れ）・再建築不可（融資不可・B/S毀損）・共有名義相続（年単位の交渉）。
- 用途地域が第一関門: **旅館業許可が取れる用途地域**のみ対象（住居専用地域は原則不可）。
- 実験: 六本松・大手門の次の仕込み1件を「空き家コンバート1号」に充て、
  新築2棟と同じ計器（投下・工期・許認可所要・稼働・単価）で実測 → 二刀流の変換レート比較表を作る。

### 4-2. プロダクト戦略: エンスイート型戸建て（新築の規格・D6）

**テーゼ: 日本の住宅の間取りは海外標準から見て時代遅れである。** タワーマンションを含め
日本の間取りは nLDK・水回り1箇所に固定されており、各寝室にトイレ・洗面（エンスイート）を
備える海外標準と乖離している。グループ・多世代・インバウンド滞在では入浴と洗面の順番待ちが
体験の最大のボトルネックになるのに、**この需要に応える供給が構造的に存在しない**。
（高砂の「浴室＋独立シャワーブース」で順番待ちが減る効果は自社レビューで実証済み。その徹底版。）

- **規格**: 各寝室にトイレ・洗面を備えるエンスイート型の新築戸建て。yah.仕様の標準設計
  （間取り・設備・動線・キーボックス位置・Wi-Fi・SSoT登録まで含む「建築の型」）として図面をIP化
- **競争優位**: 既存の一棟貸し・ホテル・民泊のどれとも被らない商品。AirDNAの供給ギャップ因子
  （§5-2）で測っている「大人数対応の不足」の、さらに内側にある空白（大人数×プライバシー）を突く
- **価格根拠**: エンスイートはADRを押し上げる（1組あたり人数×単価の最大化）。清川・高砂の
  実測ADRとの差分で「エンスイート・プレミアム」を実測し、§5の判定式に織り込む
- **金融商品化との接続**: 同一図面の量産だから、投下・工期・稼働・利回りが棟間で比較可能になり、
  §3-2の証券化適格性が生まれる。**間取りの標準化は商品戦略であると同時に資本戦略である**
- 空き家コンバート型でも「水回り分散」を改修規格の中心に置く（完全エンスイート化は構造上
  無理でも、洗面・トイレの増設は改修で可能。二刀流の商品思想を揃える）

## 5. データドリブン・ロケーション戦略（AirDNAベース）

**原則: 進出判断は人の土地勘ではなく、スコアが決める。人はスコア上位の現地確認だけを行う。**

### 5-1. データ源
- **AirDNA Research（月$34・契約決定済み・API不採用）**: 商圏別 ADR・稼働率・RevPAR・
  リスティング数と増減・季節性・リードタイム・物件タイプ構成
- 補助: 用途地域データ（自治体オープンデータ）・公示地価/基準地価トレンド・
  観光統計（自治体・観光庁）・古家付き土地の売出し情報（ポータル監視）

### 5-2. スコアリングモデル（進出スコア = 5因子の加重積）

| 因子 | 測るもの | 主データ |
|---|---|---|
| 需要 | RevPAR水準と3年トレンド・季節平準度 | AirDNA |
| 供給ギャップ | **大人数・一棟貸しの不足度**（4名超需要 ÷ 対応リスティング数） | AirDNA |
| 規制 | 旅館業可の用途地域面積・自治体の許認可運用 | 自治体 |
| 資産性 | 地価トレンド・流動性（売買事例数） | 公示地価等 |
| 取得可能性 | 古家付き土地・売地の出物頻度と価格帯 | ポータル監視 |

- yah.の構造優位: 従来事業者の第6因子「運営人員を置けるか」が、**yah.OSでは常に真**。
  競合の地図には無いピンが、yah.の地図には立つ。
- 判定式（棟単位）: 想定GMV = ADR×稼働×365 → 目標利回りから**投下上限を逆算** →
  上限内で取得・改修できる物件だけが候補になる（価格は結果ではなく入力）。

### 5-3. 運用: 候補地ランキングの機械生成
- 月次で全国の候補商圏をスコアリングし、**進出候補ランキング（トップ100リスト）**を維持。
  人が見るのは上位の変動と、保有商圏のスコア劣化アラートのみ。
- AirDNA Researchは画面運用（API不採用決定と整合）。月次チェックリストの15分で
  スコアシート（Cockpit内）を更新。将来Phase 5（価格エンジン）でPriceLabs検証時に自動化を再検討。

### 5-4. 対象都市: 6都市に限定（2026-08-18 発注者決定・D7）

**東京・大阪・京都・福岡・金沢・札幌 の6都市のみ。** それ以外には出ない。

- 選定理由: インバウンド需要の最上位・年間を通じた需要の深さ・国際空路直結、そして
  **地価が下がりにくい＝三階建て①（NAV）のテーゼが守られる**都市であること。
  観光地型（温泉地・リゾート）は需要があっても土地の資産性が弱く、対象外とする。
- 6都市に絞ること自体がブランドになる（「yah.＝6都市の一棟貸し」というコレクション性。
  FCを開く場合も、都市限定は希少性と品質管理の両方に効く）。
- **進出順はスコアが決める**: 福岡（実証済み・主戦場）→ 2都市目以降は §5-2 の進出スコアの
  序列に従う。トップ100リストは「6都市 × 区・駅圏」の商圏粒度で維持する。
- 都市別の留意（スコアの規制・資産性因子に織り込む）:
  - 京都: 旅館業・民泊規制が全国最強（参入障壁＝取れれば堀）。許認可コストを投下上限に含める
  - 東京: 土地値が高く投下/棟が跳ねる（エンスイート規格の単価上限を別途検証）
  - 札幌: 季節性が強い（季節平準度の重みを上げて評価）
  - 金沢: 市場の深さが相対的に浅い（供給ギャップが埋まりやすい＝先行者利益と裏腹）
- 拡張条件: 既進出都市で「変換レート≥1.2x・human-minutes横ばい・稼働目標達成」が再現していること。
