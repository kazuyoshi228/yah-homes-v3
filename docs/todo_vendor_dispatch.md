## 現在の状態（2026-08-19 夕）

- **完了: 23/25**（準備6・基盤4・エンジン9・画面3・運用1）。残るは B-14の画面部分・B-16 ドライラン実施・B-18 清掃への拡大
- **毎朝ひとりでに回る状態になった**（Cloud Scheduler 7:00 JST → `agencyDaily`）
  1. 周期マスタから期日の近いジョブを起票
  2. 依頼メールをGmail下書きに作成（ドライラン中。CCで山田さんに必ず見える）
  3. Gmail watch を貼り直す（有効期限7日。切れると受信が黙って止まるため毎日）
  4. 異常（沈黙・期日超過・判断待ち・未紐付けメール）があればアラートを1通
  5. 毎月1日だけ、警報そのものが鳴るかを訓練で確かめる
- **業者の返信は即時**に `agencyGmailPush`（Pub/Sub）が拾い、AIが読んで確定／代替日提案／例外へ
- **本番での実測**（2026-08-19）
  - 4段すべて成功・ハートビート4件を記録
  - 「9/15でしたら伺えます」→ confirmed（確定日を記録）
  - 「18,000円で」→ exception（AIは金額交渉をしない）
  - 期日超過ジョブ → 人へ（不自然な提案を業者にしない）
  - 警報テスト → 期日超過として検知（ok）

  毎朝おなじ依頼の下書きが増え続けていた（`requestMailAt` で一度きりに）
