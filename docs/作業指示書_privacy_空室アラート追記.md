## なぜ必要か

空室アラートは**メールアドレスと希望する宿泊日程を取得する**。これは個人情報にあたる。

現行のプライバシーポリシーは、§2「取得する情報と利用目的」に**お問い合わせ / ご予約 / アカウント / お支払い / メッセージ / プロフィール / 宿泊者名簿 / アクセス情報**の8項目を持つが、**空室アラートに該当する記載がない**。

記載のないまま取得すると、個人情報保護法の利用目的の特定・公表を満たさない。

---

## 変更内容

`src/pages/[...locale]/legal/privacy.astro` の **§2「取得する情報と利用目的」の `body` 配列**に、**1項目を追加する**。

挿入位置は「**メッセージ:**」の**直後**、「プロフィール（任意）:」の**前**（取得の重さの順に並んでいるため）。

## 書き方の約束（既存の文面に合わせる）

- **先頭に「項目名:」を置く**（既存の全項目がこの形）
- **取得する情報 → 利用目的 → 保存期間 → 取り消し方法**の順で、1段落にまとめる
- 「〜する場合があります」のような曖昧な表現は使わない。**1回限り**であることを明記する
- 他の項目と同様、**箇条書きにはせず1つの文字列**として配列に入れる

## 変更しないもの

- **§4「外部送信ツールについて」** — 空室アラートは外部送信ツールではない（自社サーバでの取得）。追記不要
- **§5「Cookieの利用について」** — 関係しない
- **§3「業務の委託と提供先」** — メール送信は既存のSMTPを使うため、既に記載済みの範囲。**新しい委託先は増えない**
- **改定日** — 既存の運用に従う（自動なら触らない・手動なら更新する）
