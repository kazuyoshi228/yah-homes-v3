# 年次の法人税を正確にする（cashflow.ts）

作成 2026-09-03 ／ 状態: **①のみ承認・実装済み（未デプロイ）／②は見送り** ／ 対象リポ: yah.homes-v2（functions）

## なぜやるか

`assumptions/corporate-tax` の注記に「課税所得は概算」「税理士の確認が要る」とある。
yah-os の資金繰り・企業価値・戦略提案書は、すべてこの税額に乗っている。
**税額がずれると、資金繰りの残高も企業価値も同じだけずれる。**

## いまの計算（cashflow.ts:567）

```
pretax = income − fixed − utilities − interest − depreciation − officer − overhead
```

### 先に訂正しておくこと

`assumptions/corporate-tax.note` に **「役員報酬・その他販管費は含まない」** とあるが、
**コードは officer も overhead も引いている。注記のほうが古い。**
→ 注記を実装に合わせて直す（Firestore の1フィールド。コード変更なし）

## 直すもの

### ① 消費税を課税所得に反映する

**いま**: `vat` は現金の出金には入っているが、`pretax` には入っていない。
2028年で **¥3,574,629**。これがまるごと課税所得に残っている。

**論点**: 税抜経理なら消費税は損益に乗らない。乗るのは **控除対象外消費税** だけ。
`assumptions/consumption-tax` は「原則課税・インボイス登録済み」を前提としており、
経理方式（税抜／税込）が書かれていない。

**方針（発注者指示 2026-09-03「消費税は支払うで入れて」）**:
`pretax` から `vatPaid`（その年に実際に納付した額）を引く。
= 税込経理に近い扱い。**現金の出方と課税所得の動きが一致する**ため、
資金繰りを見る目的では分かりやすい。

**注意**: これは会計上の正解とは限らない。税抜経理なら過大に引くことになる。
→ `assumptions/consumption-tax` に `accountingMethod` を持たせ、
   **税理士に確認するまでは「発注者指示による暫定」と明記する。**

**影響**: 課税所得が年 約¥3,500,000 下がる → 税額が年 約¥1,190,000 下がる（34%帯）

### ② 設備の減価償却を入れる

**いま**: `depreciation` コレクション9件のみ。
`assumptions/corporate-tax.missing.equipmentCount = 181` が「入っていない」と告げている。

**equipment 台帳の実態（2026-09-03 実査）**
- 198件・合計 ¥21,632,586
- 金額あり 182件／取得時期あり 188件／**両方そろっているのは182件**
- うち **長期修繕 17件 ¥7,970,700 は将来の予定**であって取得済み資産ではない
- 実際に取得済みの設備 ≈ **¥13,661,886**

**🚨 最大の論点: 二重計上のおそれ**

`depreciation` にすでにある次の2件は、equipment の中身と重なっている可能性が高い。

| depreciation の行 | 金額 | 疑い |
|---|---|---|
| 高砂 内装（定率法・4年） | ¥5,883,065 | equipment の建材・照明・金物・カーテン等がここに含まれている？ |
| 高砂 内装（定率法・8年） | ¥7,463,449 | 同上 |
| 清川 建物 | ¥14,227,847 | リフォーム費用が建物に乗っている？ |

**この2つを確かめずに equipment 182件を足すと、償却が二重になり税額が過少に出る。**
（＝資金繰りが実際より良く見える。安全側ではない）

**方針**:
1. まず **突き合わせだけ行う**。equipment の取得時期・金額を、
   depreciation の各行（および申告書の固定資産明細）と照合する
2. 重複が無いと確認できたものだけを `depreciation` に足す
3. 確認できないものは足さない。**足さないほうが税額は多めに出る＝安全側**

**そのうえで、6棟目以降のために仕組みを作る**:
equipment に `depreciable: true` / `usefulLife` / `startMonth` を持たせ、
cashflow.ts が自動で拾えるようにする（いまは depreciation コレクションに手で書いている）

**影響**: 突き合わせの結果しだい。重複が無ければ課税所得が年 数百万円 下がる
