# 法人のBS — 関連当事者カードの表示 on/off（2026-09-04）

担当: BSカードスレッド（bs.html / bs.js のみ）。**Firestore は触らない**（発注者指示 2026-09-04）。

## 何をするか

法人のBS（および 法人＋個人）で右端に出ている「関連当事者間の貸借」カードを、
**表示するかしないか**だけ切り替えられるようにする。

数字は動かない。関連当事者カードは表示専用の層（bs.js:29 のコメント）で、
資産合計・負債合計・純資産の計算に一切入っていない。**隠しても負債合計・純資産は同じ値**。

### やらないこと（明示）

- **相殺（ネッティング）はしない。** 役員借入を負債から抜いた「実質の姿」は、
  一慶氏が法人とは別人格である以上、会計上の法人BSではない。今回の範囲外
- Firestore の finance ドキュメントの追加・変更・削除はしない
- 主体スイッチ（法人／法人＋個人／個人）の3択には手を入れない

## なぜ主体スイッチに4つ目を足さないか

bs.js 冒頭のコメントのとおり、あの3つは「同時には成り立たない**主体**の択一」。
旧実装で独立スイッチ3つにしたところ「押しても効かない場面」が出たので択一にした経緯がある。
関連当事者は「同じ主体の、見せ方」なので**軸が違う**。混ぜると
（法人×関連あり／なし）×（家全体×関連あり／なし）… と組み合わせが増え、択一にした意味が消える。

→ **主体は択一のまま、関連当事者は別軸のトグル1個**。

## 画面

主体スイッチ（`.views`）の**右隣**に、同じピル型の2択トグルを置く（2026-09-04 発注者指示）。

    [ 法人のBS | 個人のBS | 法人＋個人 ]  [ 現状【家族ファンド整理前】| 家族ファンド整理後 ]

- 色は**琥珀**（`#6b5320`）。主体スイッチの青と同じにすると2つの軸が見分けられない
- 既定は **現状【家族ファンド整理前】**（今の見え方が既定。何もしなければ今までどおり）
- トグルの下に1行ヒントを出す（いま何が起きているか・合計は変わらない旨）
- **個人のBS（solo）では無効**（関連当事者カードは corp / all でしか出ないため）。
  押せない状態を `.opt.is-off`（bs.html に既存）で灰色にする——押しても無反応、を作らない

## レイアウト

| 状態 | 法人のBS の列 |
|---|---|
| 表示 on（既定） | `.cols.corp3` = 資産／負債（銀行融資の下に家族ファンド）／関連当事者 の3列 |
| 表示 off（整理後） | `.cols` 既定 = 資産／負債（2枚積み）の2列。関連当事者の中身は**家族ファンドの「山田 一慶」の行の直下に畳む**（`.fold`）——3本の明細＋小計＋差額。**合計には入れない**（一慶個人の借入なので）。その旨を注記で明示する |

`.corp3` を付けるかどうかの条件に、このトグルを足すだけ。CSSの追加は不要。

## URL

**既存キー `sub` を流用**する（`sub=norel`）。既定（表示on）はURLに載せない。

    /bs                      … 法人のBS・関連当事者あり（既定）
    /bs?sub=norel            … 法人のBS・関連当事者なし
    /bs?view=all&sub=norel   … 法人＋個人・関連当事者なし

理由: CLAUDE.md のURL標準表は共有部スレッドの管轄で、新キー（例 `rel`）の追加には
共有部スレッドへの申し送りが要る。`sub`（カード内のタブの、さらに下の切替）は表に載っている枠内で、
このカードの `data-s` に相当する切替として意味も外れない。
**将来、専用キーが欲しくなったら共有部スレッドに `rel` の追加を依頼して差し替える。**

## 触るファイル

- `bs.js`  … 状態変数1つ・`syncUrl`/`urlState.get` に `sub`・`showRelated` と `.corp3` の条件・`paintControls` の無効化

CSS の新規追加なし（`.opt` / `.opt.is-off` は既存）。`os.css` は触らない（デザインスレッド管轄）。
